# WS2812B 灯带控制

当前串口固件通过 GPIO45 控制 6 颗 XL-5050RGBC-WS2812B。使用 Adafruit NeoPixel **1.15.5**、Arduino-ESP32 Core **2.0.17**，构造参数为 `NEO_GRB + NEO_KHZ800`：800 Kbps、每颗 24 bit、MSB First。该版本在当前 Core 上使用 RMT 产生数据时序，不使用 LEDC。

## 文件与依赖

- [ws2812_led.h](../firmware/smart_esp32_serial/ws2812_led.h)：接口和硬件常量。
- [ws2812_led.cpp](../firmware/smart_esp32_serial/ws2812_led.cpp)：缓存颜色、控制亮度，执行速度灯效并按需刷新。
- [主程序](../firmware/smart_esp32_serial/smart_esp32_serial.ino)：在原有设备初始化后初始化灯带，将有效速度和指令期限状态交给主循环灯效。

`.cpp` 与 `.ino` 位于同一 Arduino 工程目录，会自动编译链接，无需修改 ROS 构建配置。安装依赖后按 [主 README](../README.md#编译与烧录) 的命令编译：

```bash
arduino-cli lib install 'Adafruit NeoPixel@1.15.5'
```

## 速度联动灯效

| 状态 | 灯效 |
| --- | --- |
| 上电等待指令、指令超时 | 六颗多色呼吸，红→黄→绿→青→蓝→品红连续渐变，每 2 秒过渡到下一色，无全灭间隔 |
| 正常零速、显式停止 | 六颗蓝色呼吸，周期 2 秒 |
| 前进 | 六颗绿色常亮 |
| 左转 | 向左逐颗累积点亮；后退转向红色，前进或原地转向黄色 |
| 右转 | 向右逐颗累积点亮；后退转向红色，前进或原地转向黄色 |
| 直线后退 | 六颗红色亮 1 秒、灭 1 秒，周期 2 秒 |

转向优先：前进或后退同时带有转向时，显示对应流水灯；线速度小于 `-0.001 m/s` 时为红色，否则为黄色。同一转向方向下切换前进/后退只改变颜色，不重置流水进度。流水每 100 ms 增加一颗，六颗全亮后全灭 100 ms，再从第一颗开始；周期 0.7 秒，快慢不随角速度变化。

正常停车的蓝色呼吸从全灭开始，1 秒达到峰值，2 秒回到全灭。上电等待和超时的多色呼吸则使用非零亮度下限：`WS2812_STANDBY_MIN_LEVEL=64`，在整体亮度 32/255 下，最亮颜色通道约为 8–32/255。相邻颜色通过平滑余弦曲线交叉渐变，每 2 秒过渡到下一色，六色完整循环 12 秒；颜色边界和循环首尾均不会全灭。自动灯效亮度上限保持 32/255。

零速度阈值为线速度绝对值不大于 `0.001 m/s`、角速度绝对值不大于 `0.01 rad/s`，仅影响灯效，不改变电机指令。灯效依据经过校验和限幅的指令判断，不代表码盘测得的实际运动状态。

有效速度帧（包括零速）沿用现有 3 秒期限；有效零速和 `0x02` 停止帧显示蓝色呼吸，速度帧期限届满后显示多色呼吸，下一帧有效速度可恢复对应灯效。零速帧超时也会进入多色呼吸，不依赖仅针对非零运动的超时告警位。显式停止帧撤销期限，保持蓝色呼吸。非法帧不会改变保存的灯效速度或续期。ROS 驱动默认每秒重发最后速度，所以仅停止发布 `/cmd_vel` 不会触发底盘超时灯效。

暂按第 0 颗（DIN 第一颗）在车辆左侧、第 5 颗在右侧实现：左转 `5→0`，右转 `0→5`。实车排列相反时，将头文件常量 `WS2812_REVERSE_ORDER` 改为 `true` 后重新编译烧录。周期、帧间隔和零阈值也集中定义在该头文件中。

状态机最多每 20 ms 更新一次画面，不使用 `delay()` 或等待循环。同一灯效下的新速度和保活帧不会重置动画；只有模式改变时从该模式起点重新开始。重复画面不发送灯带数据，时间差计算支持毫秒计数回绕。

## 接口

| 调用 | 行为 |
| --- | --- |
| `ws2812_init()` | 设置 GPIO45 输出、亮度 32/255，立即发送全灭帧；返回初始化是否成功 |
| `ws2812_set_all(r, g, b)` | 缓存整条灯带的 RGB 颜色，各分量 0–255 |
| `ws2812_set_pixel(index, r, g, b)` | 缓存指定灯珠颜色，合法索引 0–5；越界调用被忽略 |
| `ws2812_set_brightness(brightness)` | 缓存整体亮度，0–255；恢复亮度时保留原始颜色 |
| `ws2812_clear()` | 缓存六颗灯珠全灭，不改变亮度设置 |
| `ws2812_show()` | 仅发送变化的数据；锁存间隔不足时留待下次主循环发送 |
| `ws2812_update_motion(linear, angular, now_ms, standby=false)` | 根据有效速度更新灯效；上电等待或速度帧超时时传入零速及 `standby=true`，随后调用 `ws2812_show()` |

除初始化外，设置接口只改变缓存。多次设置可合并成一帧；重复设置相同状态不会重复发送。全部接口限于 `setup()`/`loop()` 所在任务，禁止在中断、定时器或 PID 任务中调用。接口不提供跨任务同步。初始化前的设置调用被忽略。主程序已通过 `pollLedMotion()` 在主循环更新并刷新灯效，初始化全灭帧后即开始多色呼吸。原有三参数调用仍可使用，默认表示有效指令或显式停止，零速显示蓝色呼吸。

底层手动接口继续保留；自动灯效运行时会覆盖手动颜色及亮度。需要持续手动控制时，临时停用主循环的 `pollLedMotion()` 调用，再由主循环调用 `ws2812_show()`。

`ws2812_init()` 的成功返回值表示缓冲区和 GPIO 初始化成功；NeoPixel 的 `show()` 无发送状态返回，无法据此确认灯带接线、供电或实际发光。

## 颜色与单颗测试

主程序已经包含头文件、初始化和主循环刷新。可在 `setup()` 中已有的 `ws2812_init()` 调用之后，临时加入以下代码测试红、绿、蓝、黄、白和关闭。此段仅用于人工颜色测试；移除后，正常主循环按速度指令运行自动灯效。

```cpp
const uint8_t test_colors[][3] = {
  {255, 0, 0},       // 红
  {0, 255, 0},       // 绿
  {0, 0, 255},       // 蓝
  {255, 255, 0},     // 黄
  {255, 255, 255},   // 白
};
for (const auto& color : test_colors) {
  ws2812_set_all(color[0], color[1], color[2]);
  delay(1);         // 确保初始化后的锁存间隔已过去
  ws2812_show();
  delay(1000);
}
ws2812_clear();
ws2812_show();
```

单颗测试：临时停用自动灯效后，调用 `ws2812_clear(); ws2812_set_pixel(0, 255, 0, 0);` 并由主循环 `ws2812_show()` 刷新，使第 0 颗变红、其余熄灭。参数仍按 RGB 传入，**不要手动交换 R/G**。

原生回归测试使用真实 NeoPixel 库，替换 Arduino GPIO、时钟和 RMT 发送入口，检查 GRB 数据、亮度恢复、越界保护、状态选择、动画周期、方向反转、保活连续性和刷新次数；指令解析测试检查停止、超时、非法帧和恢复。原生测试不能替代真机颜色及波形检查。从工作空间根目录执行：

```bash
python3 -m pytest -q src/wp_smart/smart_bringup/test/test_firmware_ws2812.py \
  src/wp_smart/smart_bringup/test/test_firmware_gearing.py
```

## 引脚与硬件

GPIO45 经 R42（1 kΩ）、74LVC1T45（3.3 V → 5 V，DIR 为高）连接灯带 DIN。保留现有 R43（20 kΩ）下拉；灯带使用 5 V 电源并与底盘共地，供电应覆盖六颗灯的实际最大电流。无需额外修改已实现的电平转换。

GPIO45 是启动配置引脚，固件仅在 `setup()` 中启用输出，不设置上拉，也不修改 eFuse。冷启动与复位时必须保持原理图要求的启动电平，避免外部设备将该引脚拉高。参见 [Espressif 启动引脚说明](https://documentation.espressif.com/esp32-s3_datasheet_en.pdf)。

GPIO21 雷达 PWM 为 **10 kHz、110/255、LEDC 通道 4**；电机 PWM 为 **20 kHz、通道 0–3**。雷达 UART RX47/TX48 和其他传感器引脚保持原配置。灯带只增加 GPIO45，不修改串口协议。

依赖实现参考：[Adafruit NeoPixel 1.15.5 的 ESP32 RMT 驱动](https://github.com/adafruit/Adafruit_NeoPixel/blob/1.15.5/esp.c)。
