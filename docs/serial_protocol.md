# ESP32-S3 串口协议

对应 [smart_esp32_serial 固件](../firmware/smart_esp32_serial/smart_esp32_serial.ino)与 [smart_bringup 驱动](../smart_bringup/src/smart_base_node.cpp)。UART1 使用 GPIO17 TX、GPIO18 RX，460800 8N1，无流控，双方共地。调试日志输出 UART0（115200）。

## 帧格式

```text
AA 55 TYPE LEN PAYLOAD CHECKSUM
CHECKSUM = (TYPE + LEN + sum(PAYLOAD)) & 0xff
```

`LEN` 为一字节，最大 64；校验覆盖类型、长度及载荷。多字节字段使用 little-endian，浮点数为 IEEE754 float32。两端支持拆包、粘包和异常后重新同步。

| 方向 | 类型 | 载荷 |
| --- | --- | --- |
| 主机→底盘 | `0x01` | `<ff`：线速度 m/s、角速度 rad/s，8 字节 |
| 主机→底盘 | `0x02` | 空载荷：立即清零目标并撤销指令期限 |
| 底盘→主机 | `0x81` | `<ffffiifhhBIIIII`：底盘状态，53 字节 |
| 底盘→主机 | `0x82` | `<Iffffff`：采样毫秒、ax/ay/az/gx/gy/gz，28 字节 |
| 底盘→主机 | `0x83` | 一圈雷达扫描的分片，16–60 字节 |

## 电机控制与超时

线速度为正表示前进，角速度为正表示左转。指令限幅为 `0.5 m/s`、`2.5 rad/s`。固件使用轮径 `0.0657 m`、轮距 `0.1805 m` 换算目标输出轴 RPM，右轮目标取反以匹配电机接线。

```text
left_rpm = (linear - angular × wheel_base / 2) × 60 / (π × wheel_diameter)
right_rpm = -(linear + angular × wheel_base / 2) × 60 / (π × wheel_diameter)
```

只有校验、长度、数值均有效的速度帧更新 3000 ms 指令期限；NaN、无穷和未知类型不会续期。独立 100 Hz 电机任务检查超时，零速度和 `0x02` 停止命令直接清零目标。停止命令不锁存，后续有效速度可恢复运动。

GPIO21 的雷达 PWM 共用此期限：上电输出 0；收到有效速度帧（包括零速）后输出 110/255，频率 10 kHz，LEDC 通道 4；满 3000 ms 未续期或收到 `0x02` 时输出 0，雷达电机停转。后续有效速度帧重新启动雷达。检查由独立 100 Hz 任务执行，雷达实际停稳存在机械惯性。

ROS 参数 `enable_cmd_vel_timeout` 默认 `false`：驱动保留最后速度，无新指令时以 1 Hz 重发，持续更新固件期限。设为 `true` 后，主机超过 `cmd_vel_timeout`（默认 3.0 秒）未收到新指令时发送零速。正常退出发送零速；通讯中断时固件按自身期限刹车；串口重连清除保存的速度。

主机持续发送零速仍维持雷达转动。因此停止发布 `/cmd_vel` 不会关闭雷达；驱动退出或串口断开后，最后一帧速度满 3 秒才关闭雷达 PWM。

## 底盘状态

`0x81` 载荷的字段如下，偏移以载荷起点为零：

| 偏移 | 类型 | 字段 |
| ---: | --- | --- |
| 0、4 | 2 × float32 | 左、右实际输出轴 RPM |
| 8、12 | 2 × float32 | 左、右目标输出轴 RPM |
| 16、20 | 2 × int32 | 左、右原始累计码盘 |
| 24 | float32 | ADC 估计电池电压，V |
| 28、30 | 2 × int16 | 左、右有符号 PWM |
| 32 | uint8 | 状态 flags |
| 33 | uint32 | 固件版本 |
| 37 | uint32 | 串口接收字节数 |
| 41 | uint32 | 接受的有效控制命令数（速度或停止） |
| 45 | uint32 | 校验错误计数 |
| 49 | uint32 | 长度或语义错误计数 |

右轮前进时原始 RPM、计数和 PWM 通常为负；ROS 驱动按配置修正码盘符号。累计计数按 32 位回绕处理。

| 掩码 | 含义 |
| --- | --- |
| `0x01` | 指令期限有效 |
| `0x02` | 非零指令已超时；下一帧有效速度清除此标志 |
| `0x04` | 估计电压低于 9.6 V |
| `0x08` | IMU 就绪 |
| `0x10` | 最近一秒收到有效雷达包 |

## IMU

MPU-60x0 使用 I²C 地址 `0x68` 或 `0x69`，`WHO_AM_I=0x68`；量程为 ±2g、±250°/s，目标采样率 100 Hz。加速度 LSB 除以 16384 后乘以 9.80665，角速度 LSB 除以 131 后转换为 rad/s。

固件发送包含重力和传感器偏置的原始六轴数据。主机发布 `/imu/data_raw`，设置 `orientation_covariance[0]=-1` 表示无姿态；其余全零协方差表示未知。主机 Madgwick 节点另行发布 `/imu/data`，航向为相对值，加速度保留重力。姿态不回传底盘，里程计由码盘积分。

## 雷达分片

| 偏移 | 字段 | 类型 |
| ---: | --- | --- |
| 0 | 本圈开始时 MCU 毫秒 | uint32 |
| 4 | 扫描序号，允许回绕 | uint16 |
| 6 | 本圈有效点总数，最多 1200 | uint16 |
| 8 | 本分片起始点下标 | uint16 |
| 10 | 点数，1–12 | uint8 |
| 11 | flags，仅 bit0：最后一片 | uint8 |
| 12 | 重复点：角度 0–35999（0.01°）、距离 mm | 2 × uint16/点 |

固件校验 X2N 包并做距离相关角度修正，在有效圈起始标志处分圈；溢出或发送拥塞时丢弃整圈。主机要求同序号、时间、总数且下标连续，不发布残缺扫描。

串口角度为修正后的原始角度；主机默认按 `(-原始角度) mod 360°` 变换，参数为 `scan_angle_offset_deg=0`、`scan_angle_direction=-1`。范围筛选和重采样在 ROS 驱动中完成，默认 450 槽、0.24–10 m。

`/scan` 使用 `laser_scan_link`：车尾 0°、右侧 90°、车头 180°、左侧 270°。该坐标系相对 `laser_link` 绕 Z 旋转 180°，机器人模型须包含相同变换。

扫描 `angle_min=0`、`angle_max=(bins-1)×angle_increment`。重采样会重排点，因此 `time_increment=0`；`scan_time` 为相邻 MCU 圈开始时间之差，首圈为 0。OLED 前方距离取完整扫描中原始角度 175°–185° 的最近有效回波，与主机前方 180° 一致。

## 传输与时间戳

固件发送前检查 UART 剩余空间，控制状态和 IMU 优先；缓冲区有界，传感器发送不等待主机消费。MCU 毫秒用于扫描组装和周期计算，ROS 时间戳采用主机接收时刻；数据未做精确时钟同步或运动去畸变。串口 sum8 仅用于传输错误检查，不提供身份认证。
