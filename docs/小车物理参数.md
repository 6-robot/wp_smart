# ESP32-S3 差动底盘参数

下表为串口固件和 ROS 驱动使用的配置值，不代表已完成实车标定。

| 参数 | 当前值 | 说明 |
| --- | ---: | --- |
| 轮径 | `0.0657 m` | 左右轮使用相同有效直径 |
| 轮距 | `0.1805 m` | 差动运动学中的左右轮间距 |
| 电机减速比 | `64:1` | 电机轴与轮轴转速比 |
| 编码器 PPR | `1024` | 电机轴每转脉冲数 |
| 电机轴四倍频计数 | `4096` | `1024 × 4` |
| 轮轴每转计数 | `262144` | `4096 × 64` |
| 左、右码盘符号 | `1`、`-1` | ROS 里程计对原始计数的方向修正 |
| 最大线速度 | `0.5 m/s` | 主机与固件指令限幅 |
| 最大角速度 | `2.5 rad/s` | 主机与固件指令限幅 |

## 参数位置

- [串口固件](../firmware/smart_esp32_serial/smart_esp32_serial.ino)：`WHEEL_DIAMETER_M`、`WHEEL_BASE_M`、`ENCODER_PPR`、`REDUCTION_RATIO`。
- [ROS 参数](../smart_bringup/config/smart_base.yaml)：`wheel_diameter`、`wheel_base`、`encoder_counts_per_wheel_rev`、`left_encoder_sign`、`right_encoder_sign`。

修改轮径、轮距或编码器计数关系时，应同步固件与 ROS 配置；修改机器人外形时还需核对模型及 Nav2 的 `robot_radius`。

## 计算关系

```text
wheel_circumference = π × 0.0657 ≈ 0.206403 m
counts_per_wheel_rev = 1024 × 4 × 64 = 262144
meters_per_count = wheel_circumference / 262144 ≈ 7.87364 × 10⁻⁷ m/count
```

前进时右轮原始计数通常为负，ROS 驱动按符号参数修正后积分 `/odom`；该里程计不融合 IMU。

## 标定方法

先确认编码器方向和每轮计数，再进行直线距离标定，最后标定原地转角。每次测量后同步调整主机和固件参数：

```text
新轮径 = 当前轮径 × 实际行驶距离 / 里程计距离
新轮距 = 当前轮距 × |里程计转角 / 实际转角|
```

距离和转角应采用独立实测值；重复多次并比较正反方向，避免用速度指令的理论距离代替实际测量。电池电压分压系数、IMU 零偏与安装方向需分别标定。
